# Cloud Computing Glossary for Translators

This glossary defines key terms used throughout the application. Use these definitions to ensure consistent, accurate translations.

## Core Concepts

### Cloud / The Cloud

**English:** Cloud, The Cloud  
**Definition:** Remote computing resources (servers, storage, applications) accessed over the internet rather than on local hardware.  
**Context:** Often used as a metaphor; "the cloud" refers to this distributed computing model.  
**Translation notes:** Many languages keep "cloud" as a loanword. Verify local preference.

### Server

**English:** Server  
**Definition:** A powerful computer that stores data and runs applications for many users simultaneously.  
**Context:** Physical machines housed in data centers.

### Data Center

**English:** Data Center  
**Definition:** A facility containing many servers, networking equipment, and storage systems.  
**Context:** The physical infrastructure underlying cloud services.

## Service Models

### IaaS (Infrastructure as a Service)

**English:** IaaS, Infrastructure as a Service  
**Definition:** Cloud provider supplies virtual machines, storage, and networking. Customer manages operating system and applications.  
**Examples:** AWS EC2, Azure VMs, Google Compute Engine  
**Translation notes:** The acronym "IaaS" is typically kept in English. Translate the full form.

### PaaS (Platform as a Service)

**English:** PaaS, Platform as a Service  
**Definition:** Cloud provider supplies development platform and runtime. Customer manages applications and data only.  
**Examples:** Heroku, Google App Engine, Azure App Service  
**Translation notes:** The acronym "PaaS" is typically kept in English.

### SaaS (Software as a Service)

**English:** SaaS, Software as a Service  
**Definition:** Cloud provider supplies complete applications accessed via browser. Customer only uses the software.  
**Examples:** Gmail, Salesforce, Microsoft 365  
**Translation notes:** The acronym "SaaS" is typically kept in English.

---

## Deployment Models

### Public Cloud

**English:** Public Cloud  
**Definition:** Cloud resources shared among multiple customers (tenants) and accessible over the public internet.  
**Key characteristics:** Multi-tenant, pay-as-you-go, managed by provider  
**Examples:** AWS, Microsoft Azure, Google Cloud Platform

### Private Cloud

**English:** Private Cloud  
**Definition:** Cloud infrastructure dedicated to a single organization, either on-premises or hosted.  
**Key characteristics:** Single-tenant, full control, higher security  
**Context:** Often chosen for regulatory compliance or sensitive data

### Hybrid Cloud

**English:** Hybrid Cloud  
**Definition:** Combination of public and private cloud resources, with orchestration between them.  
**Key characteristics:** Flexibility, "cloud bursting," data sovereignty options  
**Context:** Allows organizations to keep sensitive workloads private while using public cloud for scale

## Technical Terms

### Virtual Machine (VM)

**English:** Virtual Machine, VM  
**Definition:** A software emulation of a physical computer, running its own operating system.  
**Context:** Core building block of IaaS offerings

### Container

**English:** Container  
**Definition:** Lightweight, isolated runtime environment for applications, sharing the host OS kernel.  
**Context:** More efficient than VMs; used in modern PaaS

### Scalability

**English:** Scalability  
**Definition:** Ability to increase or decrease computing resources to match demand.  
**Related terms:** Scale up/out, elastic, auto-scaling

### Multi-tenant

**English:** Multi-tenant  
**Definition:** Architecture where multiple customers share the same infrastructure while keeping data isolated.  
**Context:** Characteristic of public cloud and SaaS

### On-premises

**English:** On-premises, On-prem  
**Definition:** Computing resources physically located within an organization's own facilities.  
**Context:** Contrasted with cloud-hosted resources

### Workload

**English:** Workload  
**Definition:** A specific application, service, or set of tasks running on computing resources.  
**Context:** Organizations consider which workloads to move to which cloud type

## Business Terms

### Lock-in (Vendor Lock-in)

**English:** Lock-in, Vendor Lock-in  
**Definition:** Difficulty or cost of switching from one provider to another.  
**Context:** A consideration when choosing cloud providers

### TCO (Total Cost of Ownership)

**English:** TCO, Total Cost of Ownership  
**Definition:** Complete cost including purchase, operation, and maintenance over time.  
**Translation notes:** Acronym may stay in English; translate the full form

### SLA (Service Level Agreement)

**English:** SLA, Service Level Agreement  
**Definition:** Contract specifying performance guarantees (uptime, response time, etc.).  
**Translation notes:** Acronym often kept in English

---

## Netflix Case Study Terms

### Streaming

**English:** Streaming  
**Definition:** Delivering media content in real-time over the internet without downloading.  
**Context:** Netflix's core service model

### Content Delivery Network (CDN)

**English:** CDN, Content Delivery Network  
**Definition:** Distributed servers that cache content closer to end users for faster delivery.  
**Context:** How Netflix delivers video globally

### Subscriber

**English:** Subscriber  
**Definition:** A person who pays for a subscription service.  
**Context:** Netflix's paying customers

## Translation Principles

1. **Consistency**: Use the same translation for a term throughout all messages
2. **Acronyms**: Generally keep technical acronyms (IaaS, SaaS, API) in English
3. **Context**: Consider where text appears (button, heading, explanation)
4. **Length**: Buttons and labels may have character limits; keep translations concise
5. **Formality**: This is educational content; use clear, accessible language
